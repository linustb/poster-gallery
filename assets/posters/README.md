# 海报素材目录与命名

## 批次目录

| 页面名称 | 目录名 |
| --- | --- |
| 第一期 | `batch-01` |
| 第二期 | `batch-02` |
| 第三期 | `batch-03` |
| 第四期 | `batch-04` |

## 分类目录

| 页面栏目 | 目录名 |
| --- | --- |
| 前期筹备 | `prep` |
| 实地调研 | `research` |
| 人物访谈 | `interview` |
| 文化寻访 | `culture` |
| 成果宣讲 | `presentation` |
| 媒体报道 | `media` |
| 总结回顾 | `summary` |

“全部海报”由网页自动聚合，不需要 `all` 目录。

## 固定文件名

每个分类可以放 9 张海报：

```text
poster-01.jpg
poster-02.jpg
poster-03.jpg
poster-04.jpg
poster-05.jpg
poster-06.jpg
poster-07.jpg
poster-08.jpg
poster-09.jpg
```

必须使用小写英文、两位编号和 `.jpg` 扩展名。

## 完整示例

第三期“人物访谈”的第一张海报：

```text
batch-03/interview/poster-01.jpg
```

第一期“成果宣讲”的第六张海报：

```text
batch-01/presentation/poster-06.jpg
```

## 推荐图片规格

- 方向：竖版
- 比例：3:4 左右
- 推荐尺寸：1500 × 2000 像素
- 格式：JPG，sRGB
- 单张大小：建议 1.5 MB 以内，最多不超过 3 MB

列表中的封面固定为 248 × 330 像素区域并使用居中裁切；点击后会按原图比例完整展示。
